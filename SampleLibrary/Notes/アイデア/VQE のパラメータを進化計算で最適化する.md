# VQE のパラメータを進化計算で最適化する

VQE の古典側の最適化は、雑音（ショット、実機の誤り）のある、評価の高い関数を相手にする。
勾配法や SPSA は値そのものの差を使うので、雑音に直接振り回される。

## 考え

- CMA-ES のように **順位だけを使う** 手法は、雑音で値がずれても、順位が変わらない限り影響を受けない
- 候補を $\lambda$ 個まとめて評価するので、同じ回路を違うパラメータで並べて投げられる（実機のジョブの単位と相性がよい）
- ショットの配分も最適化の一部にできる。序盤は少ないショットで大まかに、終盤は多く

## これまでの結果

- ショット 1024 の H2 で、CMA-ES は SPSA より平均の誤差が半分、ばらつきも小さい → [[VQE で H2（ショット 1024、SPSA と CMA-ES）|ショットありの比較]]
- ただし終盤は化学精度のまわりで揺れる。$\sigma$ が雑音に負けている

## 確かめたいこと

- [ ] ショットを段階的に増やす CMA-ES
- [ ] 評価の回数をそろえた比較に、PSO（連続版）と差分進化を加える
- [ ] 4 量子ビット以上（LiH など）で、パラメータが増えたときに順位の手法が効くか。barren plateau との関係
