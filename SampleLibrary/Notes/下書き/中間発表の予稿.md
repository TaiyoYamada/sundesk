# 雑音のある変分量子アルゴリズムと組合せ最適化における進化計算の比較（仮題）

> [!warning] 下書き
> 数字は 09-22 時点。インスタンスを増やしたら差し替える。

## 1. 背景

変分量子固有値ソルバー（VQE）[1] は、
パラメータつきの量子回路でエネルギーの期待値を測り、古典の最適化でパラメータを更新する。
実機では測定の回数が有限なので、最適化は雑音のある関数を相手にする。

組合せ最適化では、問題をイジング模型に書き換えて [2]、
量子アニーリング [3] や
シミュレーテッドアニーリング [4] で解く方法が研究されている。

## 2. 目的

量子計算の「古典側の最適化」と「組合せ最適化そのもの」の両方で、進化計算・群知能の手法が
どこで有効かを、評価の回数をそろえた比較で明らかにする。

## 3. 方法

- VQE: H2（STO-3G、2 量子ビット）、HEA、勾配法・SPSA・CMA-ES [5]
- 組合せ最適化: 重みつき Max-Cut（30 頂点）、GA・二値 PSO [6]・SA・SQA

## 4. 結果（途中）

- ショット 1024 の VQE で、CMA-ES は SPSA より平均の誤差が小さい（1.84 mHa と 3.60 mHa）
- Max-Cut では、評価 2 万回で SA だけがすべての種で最適値に届いた
- SQA と SA の優劣は、成功の数え方で変わる

## 5. 今後

- インスタンスを増やした統計的な比較
- QAOA [7] のパラメータ最適化への CMA-ES の適用
