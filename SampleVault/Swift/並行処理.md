# Swift の並行処理

Swift 6 では、データ競合をコンパイル時に検出する。

## 3 つの柱

| 仕組み | 役割 |
|---|---|
| `async`/`await` | 待つ処理を直線的に書く |
| `actor` | 可変状態を 1 つの実行文脈に閉じ込める（→ [[Actor]]） |
| `Sendable` | 実行文脈をまたいで渡してよい型の印 |

## 構造化された並行性

```swift
func loadAll(_ ids: [Note.ID]) async throws -> [Note] {
    try await withThrowingTaskGroup(of: Note.self) { group in
        for id in ids {
            group.addTask { try await load(id) }
        }
        return try await group.reduce(into: []) { $0.append($1) }
    }
}
```

> [!important] 既定の隔離
> Swift 6.2 からは、モジュールの既定を `MainActor` にできる（`SWIFT_DEFAULT_ACTOR_ISOLATION`）。
> 重い処理は `@concurrent` で明示的に外へ出す。
