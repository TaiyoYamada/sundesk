# 量子ゲート

ユニタリ行列 $U^\dagger U = I$ で表される操作。

| ゲート | 行列 | 働き |
|---|---|---|
| X | $\begin{pmatrix}0&1\\1&0\end{pmatrix}$ | ビット反転 |
| Z | $\begin{pmatrix}1&0\\0&-1\end{pmatrix}$ | 位相反転 |
| H | $\frac{1}{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}$ | 重ね合わせを作る |

## アダマールゲート

$H|0\rangle = \frac{|0\rangle + |1\rangle}{\sqrt{2}}$。[[Groverのアルゴリズム]] の最初に全状態へ振り分けるのに使う。

```swift
struct Gate {
    let matrix: [[Complex]]
    static let hadamard = Gate(matrix: [[1, 1], [1, -1]].scaled(by: 1 / 2.squareRoot()))
}
```
