# sundesk 要件定義

- 状態: 作ったものに合わせて更新している
- 最終更新: 2026-11-01

## 1. コンセプト

> **論文を集め、読み、書き込み、LaTeX から引くための、自分専用の文献管理アプリ**

Zotero のような文献管理を、Swift と SwiftUI だけで作る。Zotero のコードは使わない（[ADR 0017](adr/0017-reference-manager.md)）。

## 2. 利用者と利用形態

| 項目 | 内容 |
|---|---|
| 利用者 | 自分ひとり |
| プラットフォーム | macOS のみ。Mac 1 台で使う（同期はしない） |
| 外部との通信 | 書誌情報と arXiv の PDF を取るときだけ |
| 開発機 | Apple M3 / メモリ 16GB / macOS 27 / Xcode 27 |

## 3. 機能要件

### F1. 文献の登録

- DOI、arXiv の ID、ISBN（URL や「doi:」「arXiv:」の接頭辞が付いていてもよい）から書誌情報を引いて足す
  - DOI は doi.org の CSL JSON、arXiv は arXiv の API、ISBN は Open Library
  - arXiv の論文は PDF も取ってくる
  - 同じ DOI、arXiv の ID、ISBN の文献は、二重に足さない
- PDF をドロップするか選んで足す。PDF の最初の 3 ページに DOI か arXiv の ID があれば書誌情報を引き、なければ PDF の題名で足す
- 書誌情報を手で入れる文献も足せる
- 足すとき、サイドバーでコレクションを選んでいれば、そこに入れる
- 書誌情報はあとから手で直せ、DOI などから引き直せる

### F2. 整理と検索

- コレクション: 入れ子にできる。1 件の文献は、いくつのコレクションに入ってもよい。文献の行をドラッグして入れる
- タグ、読んだ状態（未読、読んでいる、読んだ）
- 「すべての文献」「未整理（どのコレクションにも入っていない）」、コレクション、タグで一覧を絞る。コレクションは中のコレクションの文献も見せる
- 検索: 空白で区切った語をすべて含むものを、題名、著者、年、掲載先、タグ、引用キーから探す
- 一覧は題名、著者、年、掲載先、追加日で並べ替える

### F3. PDF を読む

- 文献ごとに PDF を 1 つ添付する。PDF はアプリのデータフォルダに写す
- PDF を読むウインドウで、選んだ文をハイライトする（5 色）。ハイライトにコメントを付け、一覧から PDF のその場所へ移る
- ハイライトは PDF のファイルに書き込まない
- 文献ごとに Markdown のメモを書く（ライブプレビュー）。ハイライトを引用としてメモに足せる

### F4. 要約

- Apple のオンデバイスモデル（Foundation Models）で、PDF の本文を目的、手法、結果、限界の 4 つに要約する
- 一度に読める長さが短いので、本文を区切って要点のメモを作ってからまとめる。参考文献の節は読ませない
- 要約は文献に残し、メモに書き足せる
- 今後: タグの提案、1 本の論文への質問

### F5. 書き出し

- 選んだ文献の BibTeX をコピーする。一覧に出ている文献を .bib に書き出す
- 引用キーは「姓 + 年 + 題名の最初の語」（例: peruzzo2014variational）を自動で付け、重なれば a、b… を足す。手で変えてもよい

## 4. 非機能要件

- **Mac 標準アプリのように見え、操作できる**
  - サイドバー、一覧、詳細の 3 列（`NavigationSplitView`）と、PDF を読むウインドウのインスペクタ
  - メニューとキーボードショートカット（⌘N、⌘O、⇧⌘N、⇧⌘C、⇧⌘E、⇧⌘H）。設定のウインドウ（⌘,）
  - ダークモードに対応する
- 編集は自動で保存する（打ち終えてから 0.6 秒後）
- データは `~/Library/Application Support/com.taiyou.sundesk/Library/` にまとめ、Time Machine に入るようにする

## 5. データ設計

| 置き場所 | 持つもの |
|---|---|
| SwiftData（`library.store`） | 書誌情報、引用キー、タグ、読んだ状態、メモ、要約、コレクション、注釈。これが正 |
| `Storage/<文献の ID>/` | 添付の PDF（元のファイル名のまま） |

| モデル | 持つもの |
|---|---|
| ReferenceRecord | 書誌情報（CSL JSON の項目に合わせる。著者は JSON）、引用キー、タグ、読んだ状態、メモ、添付のパス、要約（JSON）、日時 |
| CollectionRecord | 名前、親のコレクション |
| AnnotationRecord | 文献、色、ハイライトした文、コメント、行ごとの四角（JSON） |
