# 0015. 研究の一次資料を、アプリの中の研究ライブラリに置く

- 状態: 採用（[ADR 0009](0009-workspace-layout.md) のナビゲータを変える）
- 日付: 2026-09-29

## 背景

sundesk を、研究（VQE の最適化、進化計算、群知能、量子アニーリングによる最適化）に関係するものだけをまとめる場所にする。
一般の学習ノート（study-artifact）とは完全に分ける。論文、実験の記録、コードとデータ、メモと資料といった一次資料を、
アプリの中に保存したい。

## 決定

- **置き場所**: `~/Library/Application Support/com.taiyou.sundesk/Library/`。形式は [library-format.md](../library-format.md)
  - ファイルが正で、SwiftData の索引、知識、会話は、ここから作り直せる
  - 設定から、丸ごと書き出す、書き出したものから戻す（今のものは日付を付けて横に残す）ができる
  - 開発とテストでは、リポジトリの `SampleLibrary/`（研究向けの見本）を使う。設定で切り替える
- **ナビゲータ**: ファイルの木ではなく、種類ごとの一覧（ノート、論文、実験、データ、資料）にする
- **論文**: `Papers/<キー>/` に PDF と論文メモ（書誌情報はフロントマター）。arXiv と Crossref から書誌情報を取る。
  **アプリが外と通信するのはここだけ**（要件の「外部と連携しない」を、ここだけ緩める）
- **実験**: `Experiments/<キー>/` に `experiment.json`（設定と結果の要約）、`results/`（CSV）、`figures/`、`note.md`（仮説と考察）。
  選んだ実験の収束の曲線を重ね、指標とパラメータを表で比べる
- **取り込み**: ファイルのドロップと、Python の記録用ライブラリ（`tools/sundesk-log`）の両方。記録用ライブラリは `Inbox/` に書き、
  アプリが見張って `Experiments/` に移す（通信は使わない）
- **知識とチャット**: ライブラリの Markdown（ノート、論文メモ、実験のメモ）に加え、論文の PDF の本文もページごとに検索と出典に使う

## 検討した選択肢

| 選択肢 | 良い点 | 悪い点 |
|---|---|---|
| **アプリの中のフォルダ＋種類ごとの一覧** | 散らからない。論文や実験を、それぞれに合った画面で扱える | Finder から触りにくい（書き出しで補う） |
| ふつうのフォルダ（Obsidian の Vault のように） | 他のアプリでも開ける | 研究の資料が他のファイルと混ざりやすい |
| study-artifact の一部を参照する | 背景知識をそのまま引ける | 一般の学習ノートが混ざり、検索と知識グラフのノイズになる |

## 結果

- これまでの「Vault のフォルダを選ぶ」設定は、ライブラリの書き出し・戻し・見本への切り替えに置き換えた
- `SampleVault/` は `SampleLibrary/` に置き換えた
