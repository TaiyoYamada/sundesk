# 0005. 知識グラフは Metal で描く

- 状態: 採用
- 日付: 2026-09-29

## 背景

知識グラフは数千〜数万の点と線になる見込み。眺めて楽しめることが要件で、
低レイヤーの技術も積極的に使いたい、という要望がある。

## 決定

- 知識グラフの描画は Metal で自作する
- 点と線はインスタンス描画でまとめて描き、力学モデルによる配置の計算はコンピュートシェーダーで行う
- シェーダーの計算結果は、CPU で同じ計算をした結果と比べてテストする

## 検討した選択肢

| 選択肢 | 良い点 | 悪い点 |
|---|---|---|
| **Metal で自作** | 見た目も操作感も自由に作れる。GPU の扱いを学べる | 手間がかかる。文字の描画などを自分で用意する |
| WKWebView + sigma.js / cosmos | 早く形になる。大規模でも速い | Web 技術が混ざる。細かい見た目の調整がしにくい |
| SwiftUI の Canvas | 手軽 | 数万規模では遅い |

## 結果

- フェーズ 2 で `SundeskGraphRenderer` モジュールを追加した
- 文字ラベルは、試作の結果 SwiftUI の Canvas を重ねて描くことにした（重要な点と、選んだ点の隣だけなので数が少ない）
- 反発力は、まずすべての組について計算している（数千点なら GPU で 1 フレームに収まる）。数万点を扱うときに Barnes-Hut 法などで近似する
- 研究の見本（約 300 概念、2000 関係）で、よくつながった固まりが 1 点につぶれ、つながらない点が遠くへ飛んだ。
  d3-force にならい、ばねの強さを両端の次数の小さいほうで割り、一定より遠い点からの反発を打ち切った

## 追記（2026-09-30）: 描画を作り直す

「驚きがあり、しかも毎日使える」知識グラフにするため、描画をすべて Metal に寄せて作り直した。

- **文字も Metal で描く**。形を読み込んだときに CoreText で概念とまとまりの名前を 1 枚の画像（文字の地図、2 倍の解像度）に描き、
  フレームごとには四角を並べるだけにする。縁取りはシェーダーで周りの画素を読んで付ける。SwiftUI の Canvas で毎フレーム文字を組む
  やり方は、ラベルが数百になると重く、出し入れもなめらかにできなかったため、上の「結果」の 2 つめの判断を改めた
- **1 フレームの流れ**: 前のフレームの GPU の計算が終わるのを待つ → CPU でカメラ、点の寄せ方、ラベルの置き場所を決める →
  コンピュートシェーダーで点を画面に写す（1 点につき 1 回。線、点、雲、文字はこの結果を読む）→ 半分の解像度に雲の濃さを足し合わせる →
  背景と雲、線、点、文字の順に描く → 配置を 2 回進める。CPU は同じ写し方を Swift でも持ち（ラベルと押した点を探すのに使う）、
  テストで GPU と突き合わせる
- **線**: 2 次のベジェ曲線をインスタンス描画する。まとまりの違う線は 2 つのまとまりの中心の中点へ曲げて束ねる。重い順に並べておき、
  遠くからは重い線だけを描く（LOD）。画面の外の線は頂点シェーダーで捨てる
- **点**: SDF の円。ダークでは光の暈を足し算で重ね（乗算済みのアルファで、アルファを 0 にすると足し算になる）、ライトでは白い縁と淡い影にする
- **意味のあるズーム**: 遠くではまとまりの雲（点ごとのぼかしを足し合わせた濃さの等高線）と名前、近づくと概念の名前（重ならないように重要な順に置き、
  出し入れはふわっと変える）、さらに近づくと選んだ概念が出てくるノートを、点のそばにカードで出す
- **配置**: 3 次元の Fruchterman-Reingold 法にした。平面では奥行きを 0 に保ち、3D にすると奥行きを少しずらして立体にほどく。
  まとまりの中心へ引く力と、まとまりをまたぐ線のばねを弱くすることで、まとまりが混ざらないようにした
- **驚き**（使いにくくならないものを 3 つ）
  1. 2D と 3D の切り替え。配置が立体にほどけ（平面につぶれ）、カメラも透視へなめらかに移る
  2. 育つ様子の再生。ノートを作った順（同じ日時ならパスの順）に概念が生まれ、生まれた瞬間に光る。まとまりの雲と名前も育つ
  3. 経路。⇧ を押しながら別の概念を押すと、最短の道に光の粒が流れ、カメラが道の全体へ飛ぶ
- **操作**: 選ぶと隣が同心円に寄ってくる（強い関係ほど内側、元の向きの順は保つ）。検索して選ぶと、van Wijk と Nuij の方法で
  いったん引いてから近づくようにカメラが飛ぶ。ダブルクリックと Return でノートを開き、矢印で隣へ、Esc で解除する
- **性能**: 作り物の 1,500 点・2.4 万本の線を 2800×1800 の画像に描くテストで、GPU は 1 フレーム約 3〜4 ms（Apple シリコン）。
  CPU の計算は Debug ビルドで約 2.6 ms。何も動いていなければ描かずに休む
