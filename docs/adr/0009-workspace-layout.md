# 0009. 画面は Xcode と Obsidian を合わせた構成にする

- 状態: 採用
- 日付: 2026-09-29

## 背景

sundesk は「じっくり触る実験場」で、ノートのほかに、知識グラフ、チャット、実験室、画像生成、
モデルの管理といった機能を持つ。Mac 標準のアプリのように洗練された見た目にしたい。
当初は「メモ」アプリのような 3 列を考えたが、列の数を固定しない、Xcode や Obsidian のような
構成がよいという話になった。

## 決定

- 左: **ナビゲータ**。上のアイコンで「ファイル」「検索」「タグ」を切り替える（Xcode と同じ）。
  下に機能のアイコンを 1 行で並べる（Obsidian の左端のアイコン列と同じ考え方）
- 中央: **エディタ**。ファイルも機能も、すべてタブで開く（Obsidian と同じ）
- 右: **インスペクタ**。ファイルの情報、プロパティ、タグ、目次、バックリンク
- ナビゲータとインスペクタは隠せる（⌥⌘0 など、Xcode に近いショートカット）
- 表示とソースの切り替えは ⌘E（Obsidian と同じ）
- アイコンはすべて SF Symbols を使う
- 開いているタブはウインドウごとに持つ。ファイルの木と索引はウインドウ間で共有する

## 検討した選択肢

| 選択肢 | 良い点 | 悪い点 |
|---|---|---|
| **ナビゲータ／タブのエディタ／インスペクタ** | 機能が増えてもタブとして収まる。Mac の開発者に馴染みがある | タブバーを自作する必要がある |
| 3 列（フォルダ／一覧／本文） | 「メモ」アプリと同じで分かりやすい | ノート以外の機能の置き場所に困る |

## 結果

- 機能を足すときは、`WorkspaceFeature` に 1 つ加え、タブの中身を作るだけでよい
- ウインドウの既定の大きさは 1200×800、最小は 900×560
